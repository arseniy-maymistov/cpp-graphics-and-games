# Snake Game with C++ and OpenGL

Coursework game project: a Windows Snake game with three game modes, implemented in C++ using OpenGL and GLUT.

## Overview

The coursework report describes a Snake game for Microsoft Windows, developed in C++ with OpenGL/GLUT and Visual Studio. The report states that the game supports three modes and uses an array-based representation for game data. The work is described as a team project, so individual contributions should be identified clearly.

## Topics and Features

- Snake gameplay and movement logic
- Three game modes, as stated in the report
- Interactive graphics using OpenGL and GLUT
- Windows development workflow using Visual Studio

## Technologies

C++, OpenGL, GLUT, Microsoft Windows, Visual Studio
